How it works

One task, four checkpoints

Not one model improvising end to end — a fixed pipeline where each stage has a narrower job and less room to go off the rails.

01

Planner

Reads your repo, breaks the task into concrete steps before anything is written.

READ-ONLY
02

Coder

Implements the plan. Any shell command it wants to run needs your yes first.

APPROVAL-GATED
03

Tester

Runs your actual lint/type/test tooling, then judges whether the fix is really covered.

SKEPTICAL BY DESIGN
04

Reviewer

Checks the diff for scope creep and security issues before anything reaches git.
